# KiCad & SKiDL Integration Guide

This guide describes how to configure the local environment for KiCad 8.x/10.x symbols and execute SKiDL scripts generated by **Power Circuit AI-Lite**.

## 1. Prerequisites
- **KiCad**: Version 8.x or 10.x installed.
- **Python**: 3.10+ (tested with 3.12 and 3.14).
- **SKiDL Library**: Version 2.0+ or 3.0+.

## 2. Configuring Symbol Directories
SKiDL requires access to KiCad's official `.kicad_sym` symbol files to validate pins and connections.

Set the environment variable pointing to the symbols directory:
- **Windows (PowerShell):**
  ```powershell
  $env:KICAD_SYMBOL_DIR = "D:\Kicad\share\kicad\symbols"
  # or standard KiCad 8 default:
  # $env:KICAD_SYMBOL_DIR = "C:\Program Files\KiCad\8.0\share\kicad\symbols"
  ```
- **Linux / macOS:**
  ```bash
  export KICAD_SYMBOL_DIR="/usr/share/kicad/symbols"
  ```

In Python, the generated code automatically handles directory setting:
```python
import os
kicad_sym_path = os.environ.get("KICAD_SYMBOL_DIR", r"D:\Kicad\share\kicad\symbols")
for var in ['KICAD_SYMBOL_DIR', 'KICAD8_SYMBOL_DIR', 'KICAD10_SYMBOL_DIR']:
    os.environ[var] = kicad_sym_path
from skidl import *
```

## 3. Running Electrical Rules Check (ERC)
When `ERC()` is invoked in the generated script:
- SKiDL scans every pin in every net.
- Pin directions and driving constraints are validated (e.g., ensuring inputs are connected to a driven power net).
- Warnings and errors are written to terminal output and saved to an `.erc` report.

## 4. Exporting Netlists to KiCad
Generated netlists (`circuit.net`) are formatted in KiCad netlist syntax.
To import into KiCad:
1. Open or create a new KiCad Project in KiCad PCB Editor.
2. Select **File -> Import -> Netlist...**
3. Browse and select `circuit.net`.
4. Click **Update PCB**. KiCad will instantiate the footprints and create airwires (ratsnest) ready for component placement and trace routing.
